# Проверка результата — 22 октября 2026

## Среда

Node.js 24.21.0, pnpm 11.25.0, Nuxt 4.6.1, Nitro 2.13.4, Vue 3.5.44, Playwright 1.64.0. Production-сборка запущена в локальном Cloudflare Workers runtime через `wrangler dev`; БД — настоящий эмулятор D1 с применённой SQL-миграцией.

## Что проверено

- 10 unit-тестов: оба тарифа, SQLite-запись, восстановление, изоляция устройств, конкурентные запросы без дублей, конфликт requestId, валидация, ошибка хранилища.
- 22 E2E-теста прошли (11 в Chromium, 11 в WebKit): реальная покупка и восстановление после обновления, API, клавиатурный выбор, loading/error/retry, заблокированный повторный CTA, размеры 360×800 / 390×844 / 430×932 / 360×640.
- TypeScript: `pnpm typecheck`, без ошибок.
- Production build: `pnpm build`, успешно.
- Worker packaging: `wrangler deploy --dry-run`, успешно; binding DB включён.
- Независимое ревью: существенных дефектов не обнаружено. По рекомендации добавлен E2E-сценарий потери ответа после успешно записанной покупки.

## Pixel Perfect

Сравниваются экспортированные PNG из нативного Figma-макета и браузерные PNG. DPR 1; pixelmatch `threshold: 0.1`, `includeAA: false`. Сглаживание не учитывается, области текста и иллюстрации не маскируются. Все сравнения ниже порога 1%.

| Экран              | Различающиеся пиксели |
| ------------------ | --------------------: |
| 360×800, год       |                0,449% |
| 390×844, год       |                0,393% |
| 430×932, год       |                0,323% |
| 390×844, месяц     |                0,866% |
| Загрузка           |                0,351% |
| Покупка в процессе |                0,634% |
| Ошибка             |                0,702% |
| Успех              |                0,168% |

Исходные изображения, diff и JSON-отчёты находятся в `design/`. `pnpm test:visual` и `pnpm test:visual:states` повторяют сравнение. Для статических снимков анимации отключаются; для состояний loading/error/pending используются контролируемые сетевые перехваты. Успех снимается после настоящей локальной покупки.

## Удалённый деплой — 22 октября 2026

- Публичный сервис: [discovery-island-paywall.discovery-island-paywall.workers.dev](https://discovery-island-paywall.discovery-island-paywall.workers.dev).
- Cloudflare Worker с SSR, server routes и удалённой D1 `discovery-island-purchases`, регион Eastern Europe. Миграция `0001_purchases.sql` применена.
- `TEST_BASE_URL=https://discovery-island-paywall.discovery-island-paywall.workers.dev pnpm test:e2e`: все 22 теста прошли в Chromium и WebKit на публичном HTTPS-адресе.
- `TEST_BASE_URL=https://discovery-island-paywall.discovery-island-paywall.workers.dev pnpm test:visual`: все три мобильных размера прошли, расхождение с экспортами Figma — 0,323–0,449%.
- Отдельно подтверждены HTTPS 200, загрузка двух тарифов, cookie с HttpOnly и Secure, покупка и восстановление. SQL-запрос к удалённой D1 подтвердил `offer_id`, UTC-время и 36-символьный идентификатор устройства.
- Выполнена повторная публикация: версия `9c7877d8-90ce-449d-8196-fd310f920473` заменена на `8d9c38db-31b8-4802-8bb4-60f61f9d2c9c`. После неё `/api/restore` с прежней cookie вернул исходную покупку с теми же id, offerId и createdAt.
- В ходе первого включения нового поддомена TLS временно был недоступен; первый браузерный прогон до активации сертификата завершился с ошибками. После активации HTTPS полный повторный прогон прошёл без ошибок; проверка сертификата не отключалась.

## Что остаётся внешне непроверенным

Проверка в настоящем iOS/Android webview и на физическом телефоне не проводилась. Код учитывает safe area, не запрещает zoom и прокручивается на коротком экране; реальный размер системных inset зависит от контейнера webview.
